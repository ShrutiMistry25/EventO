#  Evento – Event & Venue Booking Platform

Evento is a full-stack web application designed to simplify the process of event and venue booking. The platform connects venue providers and booking users, making it easy to manage, search, and book venues for different types of events.

##  Project Description

Evento is a full-stack web application designed to simplify the process of event and venue booking. The platform supports two roles: **Venue Provider** and **Booking User**.

Booking users can search venues based on location, date, and time, view venue details, check real-time availability, communicate with providers via chat, and complete bookings using secure payment options. Venue providers can register their venues, update pricing and availability, manage bookings, and interact with customers.

The system ensures **slot conflict prevention**, **role-based dashboards**, and a **scalable architecture**, making it suitable for events such as weddings, parties, conferences, and social gatherings.

## Project Features

- **Role-Based Login**: Separate dashboards for Booking Users and Venue Providers.
- **Venue Search**: Search venues by location, date, and time.
- **Real-Time Availability**: View available slots instantly.
- **Slot Booking**: Prevents double booking of the same slot.
- **Venue Management**: Providers can add, update, and manage venue details.
- **Chat Feature**: Real-time communication between users and providers.
- **Online Payments**: Secure payment support (UPI).
- **Simple UI**: Clean and user-friendly interface.

---

## User Roles

### Booking User
- Register and login
- Search and view venues
- Select date and time slots
- Book venues
- Chat with venue providers
- Make online payments
- View booking history

### Venue Provider
- Provider login and dashboard
- Add and manage venues
- Set pricing and availability
- Accept or reject bookings
- Chat with customers
- View booking details

## How to Run Locally

1. **Clone the repository**
    ```bash
    git clone https://github.com/your-username/evento.git
    ```

2. **Navigate to the project directory**
    ```bash
    cd evento
    ```

3. **Install the dependencies**
    ```bash
    npm install
    ```

4. **Start the development server**
    ```bash
    npm start
    ```
